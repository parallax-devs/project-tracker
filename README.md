# project-tracker
A basic Kanban-style project tracker built using HTML, CSS and JavaScript.
##live demo
[Live Website] (https://parallax-devs.github.io/project-tracker/)
#features
- Create new projects
- Add project name, category, notes
- Organize projects into four stages
- Move projects between stages
- Responsive and clean interface

#technologies used
-HTML
-CSS
-JavaScript
